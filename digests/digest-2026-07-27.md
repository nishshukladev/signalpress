## Trending repos & tools

- **[Molt: A Scalable PyTorch-Native Training Framework for Agentic Reinforcement Learning](https://arxiv.org/abs/2607.21653)** `[hot,high_value]`
  Molt is a PyTorch-native RL training framework designed for agentic RL research: compact codebase, AI-coding-assistant readable, and minimal abstraction layers. Authors argue that existing RL frameworks (RLlib, CleanRL) thread complexity across trainer, backend, and rollout logic, slowing research iteration. If you're prototyping RL-based agents, Molt offers a cleaner substrate than heavyweight frameworks; worth evaluating for fast iteration.
  Apply ▸ [micro-exp] Clone Molt, run one of the provided examples, and compare trainer code size to your current RL stack. — via **arxiv:2607.21653 (repo linked in paper)**

## Papers worth a skim

- **[Skill Self-Play: Pushing the Frontier of LLM Capability with Co-Evolving Skills](https://arxiv.org/abs/2607.22529v1)** `[hot,deep,high_value]`
  Skill Self-Play bridges environment-bound RL (narrow domains, reliable feedback) and open-ended self-evolution (broad tasks, unreliable rewards) by using agent skills as a mid-level task abstraction: skills provide verifiable task generators while maintaining diversity. The authors frame skills as both a curriculum for training and a means to escape the "hallucinated reward" trap common in self-play. Unlocks a new point in the agent-training design space between curated benchmarks and fully open-ended self-play.
  Apply ▸ [read] Read the Skill Self-Play paper to see how skills are defined, verified, and used for curriculum generation. — via **arxiv:2607.22529**
- **[TRACE-ROUTER: Task-Consistent and Adaptive Online Routing for Agentic AI](https://arxiv.org/abs/2607.22465v1)** `[hot,deep,high_value]`
  TRACE-ROUTER introduces task-consistent routing that attributes delayed, task-level outcomes to individual LLM routing decisions in multi-step agentic workflows. Instead of per-call independent routing, it learns to route across a trajectory based on the final outcome, addressing the credit-assignment problem in long-horizon agents. Production agents need to route calls across quality-cost trade-offs; this is the first framework that treats routing as a trajectory-level optimization problem.
  Apply ▸ [read] Read TRACE-ROUTER to understand how task-level feedback is backpropagated to individual routing decisions in agentic workflows. — via **arxiv:2607.22465**
- **[Agentic Context Management: Solving Agent Memory and Cost by Treating Them as Lifecycle and Architecture Problems](https://arxiv.org/abs/2607.21503)** `[hot,deep,high_value]`
  Agentic Context Management reframes agent memory not as a storage problem but as a lifecycle and architecture problem: when to retire context, when to summarize, and how to compress tool outputs. Authors argue that incumbent retrieval-based approaches ignore the fact that context is stateful and grows every turn. Production agents fail when context overflows or becomes stale; this paper proposes treating context as a first-class architectural concern.
  Apply ▸ [read] Read the Agentic Context Management paper to see how context lifecycle policies outperform pure retrieval. — via **arxiv:2607.21503**
- **[IDEAgent: Agentic Quality-Diversity Search for Research Idea Generation](https://arxiv.org/abs/2607.22375)** `[hot,deep]`
  IDEAgent applies quality-diversity (QD) search to research idea generation: instead of optimizing for quality or diversity independently, it treats ideation as a multi-objective problem and uses a MAP-Elites-style archive. The authors show that QD produces more novel and technically sound ideas than greedy or random search. Demonstrates a concrete use of evolutionary algorithms for LLM-based search; QD is underexplored in agentic workflows.
  Apply ▸ [read] Read IDEAgent to understand how quality-diversity search can be applied to LLM-based ideation tasks. — via **arxiv:2607.22375**
- **[HiKV: Hierarchical Importance-Aware KV Cache with Hardware Acceleration for LLM Decoding](https://arxiv.org/abs/2607.22389v1)** `[hot,deep,high_value]`
  HiKV introduces hierarchical KV cache compression at two granularities: Stage I evicts unimportant tokens within a fixed budget, Stage II loads only significant elements within kept tokens. Authors propose hardware acceleration (FPGA/ASIC) to exploit the hierarchical structure and show memory savings with no quality loss. KV cache is the memory bottleneck in long-context serving; this paper offers a hardware-software co-design approach that could inform production deployments.
  Apply ▸ [read] Read HiKV to understand the two-stage eviction policy and evaluate whether your serving stack can exploit hierarchical compression. — via **arxiv:2607.22389**
- **[Agentic Root Cause Analysis through Evidence-Grounded Reasoning](https://arxiv.org/abs/2607.22385v1)** `[hot,deep,high_value]`
  Agentic Root Cause Analysis frames industrial anomaly diagnosis as an evidence-grounded reasoning problem: agents formulate hypotheses, gather evidence from sensors, and justify diagnoses without labeled fault examples. The authors show that LLM-based agents can outperform black-box classifiers when interpretability and zero-shot generalization matter. Demonstrates a production-ready agentic workflow for a high-stakes domain; the evidence-grounding pattern is transferable to other diagnostic tasks.
  Apply ▸ [read] Read the Agentic Root Cause Analysis paper to extract the evidence-gathering and hypothesis-testing loop for your own domain. — via **arxiv:2607.22385**
- **[\k{appa}-LoRA: Condition Numbers Reveal Which LoRA Matrices Worth Updating](https://arxiv.org/abs/2607.22489v1)** `[deep,high_value]`
  κ-LoRA uses condition numbers to selectively update LoRA matrices: matrices with high condition numbers contribute more to adaptation and should be updated first. Authors show that selectively updating only a subset of LoRA matrices yields comparable quality at significantly lower compute cost, especially for edge deployment. Fine-tuning on-device or at scale is expensive; this gives you a principled way to prune the adaptation surface and cut costs.
  Apply ▸ [micro-exp] Compute condition numbers for your LoRA matrices using the method in κ-LoRA and prune low-contribution layers. — via **arxiv:2607.22489**
- **[DataPrep-Bench: Benchmarking LLMs as Training Data Preparators](https://arxiv.org/abs/2607.20465)** `[hot,deep,high_value]`
  DataPrep-Bench is the first unified benchmark for LLM-driven training-data preparation, spanning data construction (raw sources → supervised training data) and data quality evaluation (predicting training value before downstream experiments). Authors measure how well LLMs, agents, and workflows prepare data end-to-end, not just tokenize or filter. Data prep is the bottleneck in most training pipelines; this benchmark lets you compare tools and workflows on realistic construction tasks.
  Apply ▸ [read] Read DataPrep-Bench to identify which data-construction tasks you can automate with existing LLMs vs. where you need custom tooling. — via **arxiv:2607.20465**
- **[CausalForge: A Formally Grounded, Self-Improving Agentic Framework for Automated Research in Causal Inference](https://arxiv.org/abs/2607.22511v1)** `[hot,deep,high_value]`
  CausalForge grounds automated theoretical research in causal inference by closing the loop with the Lean proof assistant: candidate theorems are generated by an LLM, then formally verified before entering the training loop. Authors argue that LLM reviewers remain unreliable (accept fabricated papers at chance rates), so formal verification is the only reliable eval. If you're building agents for theorem-proving or formal verification, this shows how to combine LLM generation with Lean to avoid hallucinated proofs.
  Apply ▸ [read] Read CausalForge to see how the Lean proof assistant is integrated as a verifier in the agent loop. — via **arxiv:2607.22511**
- **[SceneActBench: Can Agents Act on the 3D Scenes They See?](https://arxiv.org/abs/2607.22393)** `[hot,high_value]`
  SceneActBench benchmarks VLM agents on visually conditioned action across five 3D tasks (navigation, manipulation, scene editing) in a unified agent-environment loop. Existing 3D benchmarks score text or single-object operations; this measures multi-object, multi-step action conditioned on RGB/video observations. If you're building embodied agents or 3D-aware systems, this is the first benchmark that measures action quality, not just scene understanding.
  Apply ▸ [read] Read SceneActBench to understand the task definitions and evaluate whether your VLM agent can act on 3D scenes. — via **arxiv:2607.22393**

## Pattern watch

**Agentic workflows under production stress** (HOT, DEEP): Four papers address fundamental agent deployment problems—credit assignment in routing (TRACE-ROUTER), context lifecycle (Agentic Context Management), interpretable diagnosis (RCA), and skill-driven curriculum (Skill Self-Play). All share a common architectural stance: treat agents as stateful systems with lifecycle concerns, not as per-call function dispatchers. **Selective fine-tuning for cost/edge** (DEEP, HIGH-VALUE): κ-LoRA and HiKV both exploit structure (condition numbers, hierarchical importance) to prune adaptation/serving surfaces, targeting on-device and resource-constrained settings.
