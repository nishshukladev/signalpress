  Cactus Hybrid teaches Gemma 4 to self-assess correctness via hybrid routing between model outputs and verification signals. Represents a practical instantiation of selective output verification. Calibrated uncertainty is a gating factor for deploying agents in production; this repo demonstrates a concrete technique for training verifiable self-knowledge.

## Papers worth a skim

- **[Notes to Self: Can LLMs Benefit from Experiential Abstractions?](https://arxiv.org/abs/2607.20372v1)** `[deep,high_value]`
  Notes to Self extracts reusable natural-language abstractions (strategies, reminders) from solution traces, then retrieves them at inference or uses them in RL fine-tuning. Shows ~10% MATH gain via experiential learning. Converting model failures into retrievable patterns is core to building agents that improve over deployments; this paper formalizes the mechanism.
  Apply ▸ [read] Read Notes to Self and implement the trace-to-abstraction extraction pipeline on your agent's failure logs. — via **arxiv:2607.20372**
- **[PyroDash: Cost-Efficient Token-Level Small-Large Language Model Collaborative Inference](https://arxiv.org/abs/2607.20327v1)** `[deep,high_value]`
  PyroDash performs token-level SLM→LLM routing via learned control tokens, enabling cost-aware collaborative inference. SLM emits a special token to request LLM assistance mid-generation. Hybrid routing under cost constraints is a core serving challenge; this architecture shows a trainable mechanism to selectively invoke expensive capacity.
  Apply ▸ [read] Read PyroDash and sketch a speculative-decoding variant that triggers verification with a learned confidence token. — via **arxiv:2607.20327**
- **[Sound Probabilistic Safety Bounds for Large Language Models](https://arxiv.org/abs/2607.20286v1)** `[deep,high_value]`
  Proposes Clopper-Pearson PAC bounds for computing rigorous probabilistic safety guarantees on LLM generation trees. Leverages latent-space features to prioritize exploring branches likely to produce harmful outputs. Formal safety bounds are increasingly required for regulated deployments; this paper provides a tractable algorithm with theoretical guarantees.
  Apply ▸ [read] Read Sound Probabilistic Safety Bounds and evaluate their branch-prioritization heuristic on a jailbreak detection task. — via **arxiv:2607.20286**
- **[Train the Model, Not the Reader: Decodability Supervision for Verifiable Activation Explanations](https://arxiv.org/abs/2607.20379)** `[deep,high_value]`
  Train the Model, Not the Reader shows reconstruction-based explanations of activations are structurally insensitive to false claims. Proposes decodability supervision that penalizes explanations with flippable unpenalized claims. Verifiable interpretability is critical for debugging agents; this paper reveals a fundamental flaw in autoencoder-based explanations and offers a fix.
  Apply ▸ [read] Read Train the Model, Not the Reader and test whether your SAE explanations survive claim-flipping on your own model. — via **arxiv:2607.20379**
- **[Beyond Relevance-Centric Retrieval: Rubric-Oriented Document Set Selection and Ranking](https://arxiv.org/abs/2607.19747)** `[deep,high_value]`
  Beyond Relevance-Centric Retrieval proposes rubric-oriented document set evaluation that scores inter-document properties (redundancy, conflict, complementarity) instead of per-document relevance. Includes evaluate-diagnose-optimize framework. Set-level retrieval quality determines RAG ceiling; this framework provides actionable diagnostics for improving document selection.
  Apply ▸ [micro-exp] Evaluate your RAG pipeline using the rubric-oriented metrics from the paper and identify top redundancy/conflict sources. — via **arxiv:2607.19747**
- **[SLPO: Scaling Latent Reasoning via a Surrogate Policy](https://arxiv.org/abs/2607.19691)** `[hot,deep,high_value]`
  SLPO trains latent reasoners via a surrogate policy that provides verifiable RL signal without decoding every intermediate step. Addresses the imitation-bound limitation of latent CoT models. Latent reasoning is compute-efficient but lacks RL-based improvement; this paper demonstrates a practical mechanism to close that gap.
  Apply ▸ [read] Read SLPO and compare its surrogate policy approach to standard RL on a reasoning task you care about. — via **arxiv:2607.19691**
- **[AutoIndex: Learning Representation Programs for Retrieval](https://arxiv.org/abs/2607.18603)** `[deep,high_value]`
  AutoIndex learns executable representation programs that transform raw documents before indexing, rather than tuning retrievers or rerankers. Uses validation-guided program search with agent-driven diagnosis. Preprocessing is an overlooked lever for retrieval quality; this framework automates search over transformations that improve downstream performance.
  Apply ▸ [weekend-build] Apply AutoIndex to your retrieval pipeline and measure whether learned transformations beat manual preprocessing rules. — via **arxiv:2607.18603**
- **[Transcription Policy as a Latent Variable: Activating Controllable Verbatim ASR with Word-Level Timing](https://arxiv.org/abs/2607.18934)** `[high_value]`
  Proposes task tokens trained on parallel verbatim/intended transcript pairs to control ASR transcription style, reducing WER attribution to style mismatch from ~60% and improving word-level timing reliability. Controllable ASR is a practical prerequisite for reliable agent voice interfaces; this approach demonstrates measurable improvements.
  Apply ▸ [micro-exp] Test whether adding transcription style control tokens to your ASR pipeline reduces downstream task error on agent voice inputs. — via **arxiv:2607.18934**

## From the social layer
