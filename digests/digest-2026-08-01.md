## Papers worth a skim

- **[$β$-OPSD: Deriving with Policy Optimization, Training with Self-Distillation](https://arxiv.org/abs/2607.28582v1)** `[deep,high_value]`
  β-OPSD frames on-policy self-distillation as a policy-optimization family parameterized by β, the KL penalty weight anchoring the student to a reference. Tuning β from its implicit fixed value of 1 stabilizes training and improves reasoning performance, addressing a known brittleness in OPSD workflows. If you're training reasoning agents via self-distillation, this parameter gives you a principled lever to fix training instability without ad-hoc hacks.
  Apply ▸ [read] Read Section 3 of β-OPSD, identify the β sweep results, and apply the recommended range to your next OPSD experiment. — via **arxiv:2607.28582**
- **[OmniScope: Modality-Decoupled Token Compression for Omnimodal Large Language Models](https://arxiv.org/abs/2607.23193)** `[hot,deep,high_value]`
  OmniScope decouples token compression per modality, using the query as a shared anchor instead of one modality guiding the other. This prevents cross-modal salience mismatch from dropping answer-critical tokens under aggressive compression in omnimodal LLMs. If you're serving multimodal models under token budgets, this architecture pattern can reduce hallucinations caused by naive cross-modal pruning.
  Apply ▸ [read] Read OmniScope Section 2.2 on modality-decoupled compression, compare to your current token-pruning strategy, and prototype the query-anchored scoring function. — via **arxiv:2607.23193**
- **[β-OPSD: Deriving with Policy Optimization, Training with Self-Distillation](https://arxiv.org/abs/2607.28582)** `[hot,deep,high_value]`
  Same paper as #37 (β-OPSD), now indexed via HF with higher upvote momentum (17 upvotes). On-policy self-distillation is a key technique for improving reasoning models, and this work formalizes the brittleness engineers encounter and provides a tunable hyperparameter solution. Knowing that vanilla OPSD is β=1 of a broader family lets you debug training failures by sweeping β instead of guessing at data or schedule changes.
  Apply ▸ [read] Review the β sweep in Figure 2 of β-OPSD and re-run your last failed OPSD experiment with β ∈ [0.5, 2.0]. — via **arxiv:2607.28582**
- **[Σ-Mem: An Online Reliability Memory for LLM-based Multi-Agent Systems](https://arxiv.org/abs/2607.27958)** `[deep,high_value]`
  Σ-Mem is an online reliability memory for multi-agent systems that records competence evidence and peer-relationship signals, enabling agents to reason about trust under uncertainty when direct verification is impossible. This moves beyond content-only memory toward modeling which agents are reliable for which tasks. If you're building multi-agent systems where agents coordinate or vote, tracking reliability prevents correlated errors from propagating unchecked.
  Apply ▸ [micro-exp] Implement Σ-Mem's competence scoring function (Section 3.1) in a toy multi-agent setup and measure whether it catches an agent that confidently hallucinates. — via **arxiv:2607.27958**
- **[See2Think: Do Multimodal Models Really Use Intermediate Visual States?](https://arxiv.org/abs/2607.26769)** `[hot,deep,high_value]`
  See2Think is a unified evaluation framework for multimodal reasoning that tests whether models actually use intermediate visual states (sketches, annotations, tool outputs) or just rely on language priors. It provides coverage across diverse tasks and diagnoses generation, rendering, and usage of visual intermediates separately. If you're evaluating multimodal agents, this framework exposes whether your model is truly multimodal or just using images as a prompt cue.
  Apply ▸ [weekend-build] Run See2Think's visual-state ablation protocol on your multimodal agent and quantify the performance gap when intermediate images are replaced with noise. — via **arxiv:2607.26769**
- **[Is Deep Research Reliable? Misleading Knowledge Induces False Conclusions](https://arxiv.org/abs/2607.20891)** `[deep,high_value]`
  MisKnow-Agent is a framework for testing whether misleading but credible knowledge in retrieval or web search causes deep-research agents to propagate false conclusions into final reports. It systematically injects misinformation and measures downstream adoption, revealing a critical failure mode in long-horizon workflows. If you're deploying research agents, this eval pattern helps you measure and mitigate the risk of confidently wrong outputs caused by adversarial or low-quality sources.
  Apply ▸ [micro-exp] Inject a single plausible-but-false claim into your agent's retrieval corpus and trace whether it appears in the final output using MisKnow-Agent's methodology. — via **arxiv:2607.20891**
- **[LEDGERMIND: Provenance-Constrained Multimodal Agentic Reasoning with a Structured Evidence Ledger](https://arxiv.org/abs/2607.28374)** `[deep,high_value]`
  LEDGERMIND treats multimodal agent trajectories as provenance-constrained state machines, normalizing tool outputs into a Structured Evidence Ledger that enables fine-grained auditing of whether answers are grounded in evidence or hallucinated. This shifts evaluation from final-answer accuracy to process-level correctness. If you're building high-stakes multimodal agents, this architecture makes it possible to audit which intermediate outputs contributed to each claim in the final answer.
  Apply ▸ [weekend-build] Implement LEDGERMIND's Structured Evidence Ledger schema for your agent's tool outputs and log one trajectory to verify provenance for each final claim. — via **arxiv:2607.28374**
