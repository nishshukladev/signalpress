- **[Kitesurf: Agent-first browser that runs in V8 isolates](https://blog.cloudflare.com/kitesurf/)** `[hot,deep]`
  Cloudflare shipped Kitesurf, an agent-first browser runtime that runs in V8 isolates on Workers, providing sub-100ms cold-starts and multi-tenant isolation for web automation agents. It exposes a Puppeteer-like API with sandboxed execution, making it viable to run untrusted agent code at the edge. Agent deployment architecture (cold-start latency, isolation, scale) is rapidly becoming table-stakes; Kitesurf shows how edge-native isolation enables agent APIs.

- **[Activity Frames: Deterministic Screen-Activity Compilation for Agent Memory and Replay](https://arxiv.org/abs/2608.05784)** `[hot,deep,high_value]`
  Activity Frames is a zero-model, deterministic pipeline that compiles screen-capture streams into typed agent memory: segmented episodes with application, site, timing, input volume, and pointers to raw evidence. It eliminates the need for agents to re-derive user routines by storing what the user did, not just what they said, enabling replay and context retrieval without inference cost. Agent memory architecture is a frontier problem; Activity Frames provides a production-ready, model-free compile step that reduces inference waste and enables provenance.
  Apply ▸ [micro-exp] Instrument a local screen-capture stream with Activity Frames and measure compression ratio and retrieval latency vs. raw logs. — via **Activity Frames (arXiv 2608.05784)**
- **[DataSpace: Benchmarking Data Agents for Verifiable Analytics over Heterogeneous Workspaces](https://arxiv.org/abs/2608.03451)** `[hot,deep,high_value]`
  DataSpace is a benchmark for data agents that produce verifiable tabular results from tasks spanning databases, structured files, long documents, and multimedia. It unifies heterogeneous evidence discovery, complete table outputs, and deterministic evaluation in 200+ tasks drawn from real organizational analytics workflows. Data-agent evals are fragmented across retrieval, SQL, and open-ended tasks; DataSpace provides a unified, verifiable benchmark that mirrors production analytics.
  Apply ▸ [micro-exp] Run a baseline data agent on DataSpace and profile failure modes (retrieval, schema inference, cross-source joins) to prioritize improvements. — via **DataSpace benchmark**

## Papers worth a skim

- **[RRC: Unlocking Generative Reward Models in LLM Reinforcement Learning via Ranking-Based Reward Construction](https://arxiv.org/abs/2608.06310v1)** `[hot,deep,high_value]`
  RRC (Ranking-based Reward Construction) bridges the gap between generative reward models (which excel at pairwise ranking) and scalar-reward RL by converting rankings into utilities via a Bradley–Terry layer. The paper shows empirical RL gains over discriminative reward models on coding and instruction-following tasks. Generative reward models are underutilized in agent RL; RRC provides a concrete, implementable adapter that unlocks their potential without re-architecting pipelines.
  Apply ▸ [weekend-build] Reproduce RRC's Bradley–Terry adapter on a small coding task using an open generative reward model and compare PPO convergence to a discriminative baseline. — via **RRC (arXiv 2608.06310)**
- **[Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations](https://arxiv.org/abs/2608.06305v1)** `[hot,deep,high_value]`
  This paper argues that chunk-embed-topK retrieval structurally fails for table-heavy documents (e.g., financial reports) where 86.8% of content is table rows and identical figures compete in embedding space. It replaces retrieval with a deterministic, interpretable agentic pipeline of typed operations (column scans, cross-table joins) that surface evidence without embedding collisions. Financial/regulatory RAG is a high-value domain where standard retrieval fails silently; this paper provides a named architectural alternative and a measurement playbook.
  Apply ▸ [read] Audit a table-heavy RAG use-case for top-k embedding collisions and prototype a rule-based column-scan fallback using the paper's typed operation framework. — via **Beyond Top-K (arXiv 2608.06305)**
- **[On-Policy Self-Distillation without Any Supervision](https://arxiv.org/abs/2608.06296v1)** `[hot,deep]`
  Unsupervised On-Policy Self-Distillation (U-OPSD) removes all external supervision (ground-truth, environment feedback, larger models) from on-policy distillation by using only internal consistency across sampled rollouts. The method filters self-generated outputs via agreement and distills on the filtered set, showing gains on reasoning tasks. Reducing reliance on external supervision lowers the barrier to post-training; this paper shows a concrete consistency-filtering recipe that works without oracles.
  Apply ▸ [micro-exp] Implement U-OPSD's agreement-based filtering on a small instruction-following task and measure distillation quality vs. baseline self-distillation. — via **U-OPSD (arXiv 2608.06296)**
- **[NeSy-RAG: Neuro-Symbolic RAG for Explainable Question Answering](https://arxiv.org/abs/2608.06292v1)** `[hot,deep,high_value]`
  NeSy-RAG replaces opaque LLM reasoning with a neuro-symbolic pipeline: it translates queries into first-order logic, retrieves facts into a symbolic KB, and exposes a proof trace that attributes every claim to specific evidence. The framework detects missing context via open-world reasoning and surfaces it as explicit queries, making failures debuggable. Explainability and verifiability are blockers for high-stakes RAG; NeSy-RAG provides a composable architecture that makes reasoning inspectable and attributable.
  Apply ▸ [weekend-build] Reproduce NeSy-RAG's query-to-logic translation and KB reasoning on a toy QA dataset and compare proof-trace quality to standard RAG. — via **NeSy-RAG (arXiv 2608.06292)**
- **[EnvACE: Internalizing Environment Dynamics via World Rehearsal for Agentic Reinforcement Learning](https://arxiv.org/abs/2608.06197)** `[hot,deep,high_value]`
  EnvACE replaces external environment interaction during training with world rehearsal: the agent generates a tool call, then simulates the environment response by role-playing the tool, and uses that imagined trajectory for RL updates. This removes the need for expensive executable sandboxes or synthesized traces during training. Environment cost is a major RL bottleneck for tool-use agents; EnvACE provides a concrete self-play recipe that internalizes environment dynamics without external execution.
  Apply ▸ [weekend-build] Reproduce EnvACE's world-rehearsal loop on a simple tool-use task (e.g., calculator) and measure sample efficiency vs. ground-truth environment training. — via **EnvACE (arXiv 2608.06197)**
- **[BaKron: Efficient Quantization with Kronecker-Factored Hessians](https://arxiv.org/abs/2608.06291v1)** `[hot,deep]`
  BaKron accelerates GPTQ-style quantization by applying adaptive rounding in the Kronecker-factored weight domain, avoiding expensive vectorization. It uses two-sided Hessian approximations to capture output correlations while maintaining per-layer computational tractability, enabling faster quantization for large models. Quantization speed is a deployment bottleneck; BaKron shows how to exploit Kronecker structure for faster adaptive rounding without sacrificing two-sided geometry.
  Apply ▸ [read] Compare BaKron's Kronecker-factored approach to standard GPTQ on a mid-size model and measure quantization wall-time and accuracy delta. — via **BaKron (arXiv 2608.06291)**
