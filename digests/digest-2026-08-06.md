## Papers worth a skim

- **[Reasoning Core: Designing Broad Procedural Data for Completion-Supervised Reasoning Training](https://arxiv.org/abs/2608.05148v1)** `[hot,deep,high_value]`
  Reasoning Core presents 50 procedural generators spanning math, logic, planning, code, and state tracking with semantic scorers and difficulty controls. Completion-supervised training on procedural data competes with process supervision, offering a scalable alternative for reasoning training. Procedural data generation is cheaper and more controllable than human annotation; mastering this unlocks custom reasoning evals and training sets.
  Apply ▸ [micro-exp] Reproduce one generator from Reasoning Core (e.g., a simple planning or logic task) and score outputs against a small model. — via **https://arxiv.org/abs/2608.05148v1**
- **[OctoLong: Mid-Training On Cross-Repository Code Contexts Enhances Long-Context Modeling](https://arxiv.org/abs/2608.05141v1)** `[hot,deep,high_value]`
  OctoLong mid-trains on cross-repository code contexts using AST parsers, language servers, and package managers to construct long-distance dependencies. This addresses the scarcity of long-context code data and improves context modeling for coding agents. Cross-repo context is essential for real-world coding agents; learning to engineer synthetic long-context corpora is a high-leverage DX skill.
  Apply ▸ [weekend-build] Use tree-sitter and a language server protocol client to instrument a small repo and generate cross-file dependency traces. — via **https://arxiv.org/abs/2608.05141v1**
- **[Toward Skill-Native LLMs: Skill Entropy for Benchmarking and Training Long-Horizon Reasoning](https://arxiv.org/abs/2608.05139v1)** `[hot,deep,high_value]`
  This paper defines cross-skill long-horizon tasks (multi-step tasks requiring skill-switching) and introduces skill entropy to measure how well models transition between reasoning skills. It offers a principled eval framework for long-horizon reasoning chains. Skill-switching is the bottleneck in multi-step agent workflows; skill entropy gives you a quantitative lens to diagnose and train for it.
  Apply ▸ [micro-exp] Implement the skill entropy metric on a small set of multi-step tasks (math → planning) to measure skill-transition quality. — via **https://arxiv.org/abs/2608.05139v1**
- **[Chained Recursive Language Models for Multi-Iteration Reasoning](https://arxiv.org/abs/2608.05124v1)** `[hot,deep,high_value]`
  Chained Recursive Language Models (Chained RLM) decompose long-context reasoning into multiple inference passes, each extracting, verifying, or aggregating evidence. This reduces error propagation in multi-hop tasks like counting and ordering. Multi-pass reasoning patterns are underexplored; mastering chained inference opens a path to more reliable long-horizon agents.
  Apply ▸ [micro-exp] Implement a two-pass chain (extract + verify) on a simple counting task and compare error rates to single-pass inference. — via **https://arxiv.org/abs/2608.05124v1**
- **[Item Response Theory for AI Safety](https://arxiv.org/abs/2608.05086v1)** `[hot,deep,high_value]`
  Applies Item Response Theory (IRT) to safety benchmarks, inferring latent safety traits and psychometric properties of test items. This addresses benchmark duplication, heavy correlation, and sandbagging, offering a principled measurement framework. IRT brings rigor to eval design and interpretation; applying psychometrics to LLM evals is a scarce, high-signal skill for senior engineers.
  Apply ▸ [read] Read the IRT methodology section and fit a simple 1PL IRT model to a small safety benchmark using pyirt or mirt. — via **https://arxiv.org/abs/2608.05086v1**
- **[Self-Evolving Coding Agents](https://arxiv.org/abs/2608.03392)** `[hot,deep,high_value]`
  Self-Evolving Coding Agents explores how agents can inspect repos, run tests, debug, and generate patches while learning from deployment feedback. It surveys self-evolution mechanisms and identifies gaps in static post-deployment agents. Self-evolution is the frontier of agent research; understanding the taxonomy of learning loops prepares you for the next wave of agent architectures.
  Apply ▸ [read] Read the paper and map the self-evolution mechanisms (e.g., experience replay, curriculum) to existing agent frameworks like SWE-agent. — via **https://arxiv.org/abs/2608.03392**
- **[ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment](https://arxiv.org/abs/2608.05102)** `[hot,deep,high_value]`
  ABSeeker introduces Answer-Backtracked Credit Assignment (ABC) for training long-horizon search agents, assigning fine-grained credit to useful actions vs. erroneous ones. This improves SFT and RL by distinguishing intermediate step quality. Credit assignment is the core RL challenge in multi-step agents; ABC offers a concrete, backprop-friendly mechanism you can plug into existing RLVR pipelines.
  Apply ▸ [micro-exp] Implement a minimal ABC loss on a synthetic multi-step search task and compare gradient signal to uniform step weighting. — via **https://arxiv.org/abs/2608.05102**
- **[Agent Against Agent: An Agentic System for Automatic Prompt Injection Red Teaming](https://arxiv.org/abs/2608.05108)** `[hot,deep,high_value]`
  PIMiner is an agentic red-teaming system for prompt injection that outperforms RL-based methods and generalizes better to new target LLMs. It addresses the brittleness of attacker models trained via RL. Prompt injection is a critical security surface for deployed agents; understanding agentic red-teaming positions you to build or audit defenses.
  Apply ▸ [read] Read the PIMiner methodology and compare its agentic search to existing RL red-teamers like those in the OpenAI safety literature. — via **https://arxiv.org/abs/2608.05108**
- **[OneDayAgent: Towards a Long-Horizon Harness for Autonomous Agents](https://arxiv.org/abs/2608.05013)** `[hot,deep,high_value]`
  OneDayAgent is a long-horizon harness for open-ended everyday tasks spanning work, study, and life. It jointly manages goal drift, state loss, and context overflow—three failure modes that prior work addressed in isolation. Long-horizon, cross-environment tasks are the next eval frontier; a unified harness lets you benchmark and debug agents systematically.
  Apply ▸ [read] Read the OneDayAgent paper and identify the joint failure modes, then map them to existing agent benchmarks like WebArena or InterCode. — via **https://arxiv.org/abs/2608.05013**
- **[The Personalization Mirage: How LLMs Fabricate User Profiles, and Why Self-Monitoring Misleads](https://arxiv.org/abs/2608.04570)** `[hot,deep,high_value]`
  MirageBench studies over-inference in personalized LLMs: the phenomenon where models fabricate user attributes beyond evidence. It introduces 150 personas, 6 personalization tasks, a faithfulness taxonomy, and finds that self-monitoring misleads. Personalized agents are shipping at scale; understanding hallucination in user modeling is critical for safe, trustworthy deployment.
  Apply ▸ [micro-exp] Run a small personalization task using MirageBench personas and measure over-inference vs. evidence-grounded inference. — via **https://arxiv.org/abs/2608.04570**
