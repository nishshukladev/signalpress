## Papers worth a skim

- **[Learning When to Trust via Selective Context Preference Optimization](https://arxiv.org/abs/2608.06377v1)** `[deep,high_value]`
  MIST (arXiv 2608.06377) trains models to selectively trust context by rendering each reasoning item under four matched conditions (clean, misleading, correct-context, no-context). It avoids the failure mode where robustness training makes models ignore all context, even when useful. Selective trust is critical for RAG and agentic systems where some retrieved context helps and some hurts; this offers a benchmark and training method.
  Apply ▸ [read] Review the MIST benchmark format and adapt the four-condition setup to your own RAG or agent context evaluation pipeline. — via **MIST benchmark (arXiv 2608.06377)**
- **[The Bitter Lesson of Tool Calling](https://arxiv.org/abs/2608.06370v1)** `[hot,deep,high_value]`
  The Bitter Lesson of Tool Calling (arXiv 2608.06370) systematically compares programmatic tool calling (PTC, code-based) vs. rigid JSON tool calls across model generations and benchmarks. PTC lets agents chain and parallelize tools naturally but requires code-capable models. Choosing JSON vs. code-based tool calling affects agent flexibility and error rates; this paper gives you empirical guidance under realistic conditions.
  Apply ▸ [read] Compare your current JSON tool-call agent to a PTC version using the benchmark tasks from this paper to measure chaining and error-handling gains. — via **arXiv 2608.06370 benchmark**
- **[AV-AIVAT: 74x Cheaper Agent Evaluation with Certified Anytime-Valid Stopping in Imperfect-Information Games](https://arxiv.org/abs/2608.06362v1)** `[deep,high_value]`
  AV-AIVAT (arXiv 2608.06362) provides certified anytime-valid stopping for agent evaluation in imperfect-information games, cutting eval costs by 74×. It stops as soon as evidence suffices while keeping confidence intervals valid, unlike naive optional stopping. Expensive agent evals can stop early without invalidating CI, saving compute and expert time while keeping statistical guarantees.
  Apply ▸ [read] Apply AV-AIVAT stopping rules to your next agent head-to-head eval to cut eval budget while preserving statistical validity. — via **AV-AIVAT (arXiv 2608.06362)**
- **[Benchmarking the Benchmarks: Evaluating Benchmarks for Conversational Agents](https://arxiv.org/abs/2608.06329v1)** `[deep,high_value]`
  Benchmarking the Benchmarks (arXiv 2608.06329) introduces a reference-free LLM-judge framework to assess conversational-agent benchmark quality: consistency, complexity, and policy coverage. It provides actionable diagnostics of benchmark weaknesses. Poor benchmarks yield unreliable agent evals; this framework lets you audit your own benchmarks before investing in training or tuning.
  Apply ▸ [micro-exp] Run the LLM-judge framework on your existing agent benchmark to identify inconsistencies and low-coverage tasks. — via **arXiv 2608.06329 framework**
- **[HarnessOpt-Bench: Evaluating LLMs at Harness Optimization](https://arxiv.org/abs/2608.06301v1)** `[hot,deep,high_value]`
  HarnessOpt-Bench (arXiv 2608.06301) measures LLM capability at harness optimization: iteratively improving prompts, tools, control flow, and orchestration code around an LLM. It defines a common protocol for evaluating this meta-capability. Harness optimization is how agentic systems improve in practice; this benchmark lets you track progress and compare approaches systematically.
  Apply ▸ [read] Adopt the HarnessOpt-Bench protocol to measure how well your LLM can optimize its own agentic harness in a controlled setting. — via **HarnessOpt-Bench (arXiv 2608.06301)**
- **[OSReward: Instituting Standardized Evaluation for Cross-Platform Computer-Use Reward Models](https://arxiv.org/abs/2607.28609)** `[hot,deep,high_value]`
  OSReward (arXiv 2607.28609) standardizes cross-platform computer-use reward-model evaluation. VLMs increasingly judge CUA trajectories; this paper benchmarks those judges at scale across operating systems and tasks. Reward models for computer-use agents are critical for RL and data curation; OSReward gives you a reproducible way to pick and tune them.
  Apply ▸ [read] Evaluate your current CUA reward model against OSReward's cross-platform tasks to identify OS-specific failure modes. — via **OSReward benchmark (arXiv 2607.28609)**
- **[CalibForge: Adversarial Solver Calibration for Scaling Learnable Terminal Tasks](https://arxiv.org/abs/2608.06352)** `[hot,deep,high_value]`
  CalibForge (arXiv 2608.06352) synthesizes terminal tasks that are appropriately challenging for a given solver via adversarial solver calibration. Multi-solver calibration targets disagreement to ensure tasks are neither trivial nor impossible. Terminal-agent training needs tasks at the right difficulty frontier; CalibForge automates task synthesis and calibration to keep your agent learning.
  Apply ▸ [micro-exp] Use CalibForge to generate a set of terminal tasks calibrated to your current agent's skill level and track improvement over training. — via **CalibForge (arXiv 2608.06352)**
- **[Recursive Synthesis for Long-Horizon Terminal Tasks](https://arxiv.org/abs/2608.05466)** `[hot,deep,high_value]`
  Recursive Synthetic Terminal Tasks (arXiv 2608.05466) generates long-horizon terminal tasks by recursively synthesizing instruction, environment, solution, and verifier while keeping them mutually consistent. Addresses the high cost (hundreds to thousands per task) of human-authored terminal tasks. Long-horizon terminal training data is a bottleneck; RST offers a scalable synthesis method that maintains correctness without human authoring.
  Apply ▸ [read] Apply the RST recursive synthesis pattern to generate 10 long-horizon tasks for your terminal agent and verify consistency using the paper's constraints. — via **RST framework (arXiv 2608.05466)**
