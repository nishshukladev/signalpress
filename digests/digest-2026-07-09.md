## Papers worth a skim

- **[Agon: Competitive Cross-Model RL with Implicit Rival Grading of Reasoning](https://arxiv.org/abs/2607.07690v1)** `[hot,deep]`
  Agon (arXiv 2607.07690) introduces competitive cross-model RL where two models solve the same problem and grade each other's reasoning traces, not just final answers. The framework addresses GRPO's blindness to reasoning quality when only the end result is verified. If you're tuning reasoning models, Agon's rival-grading loop offers a publishable technique to improve chain-of-thought without hand-labeled traces—scarce skill at Staff+ level.
  Apply ▸ [micro-exp] Implement a two-model trace-comparison loop on a small math or coding dataset and measure quality delta over baseline GRPO. — via **Agon (arXiv 2607.07690)**
- **[Max Out GRPO Signal: Adaptive Trace Prefix Control for Hard Reasoning Problems](https://arxiv.org/abs/2607.07674v1)** `[hot,deep]`
  AdaPrefix-GRPO (arXiv 2607.07674) turns prefix length into a continuous difficulty knob for hard reasoning problems where vanilla GRPO stalls (zero gradient when no rollout succeeds). The feedback controller adapts prefix length throughout training to max out the learning signal. Hard problems are where models fall behind; controlling difficulty dynamically is a lever you can tune in your own RL pipeline and publish as a reproducible recipe.
  Apply ▸ [micro-exp] Add adaptive prefix control to your GRPO training loop on a challenging reasoning benchmark and log gradient signal over epochs. — via **AdaPrefix-GRPO (arXiv 2607.07674)**
- **[RL Post-Training Builds Compositional Reasoning Strategies](https://arxiv.org/abs/2607.07646v1)** `[deep,high_value]`
  RL Post-Training Builds Compositional Reasoning Strategies (arXiv 2607.07646) uses a rewrite-grammar environment to prove RL can compose primitive skills into higher-level strategies, not just amplify memorized patterns. Every rewrite is audited, offering full transparency into what the model learned. Understanding whether RL creates novel reasoning or just scales retrieval is a Staff+ research question; this controlled setup gives you a reproducible testbed to explore compositional learning.
  Apply ▸ [read] Read the paper and identify one primitive+composite task pair in your domain to test whether your RL loop composes or memorizes. — via **arXiv 2607.07646**
- **[From Noisy Traces to Root Causes: Structural Trajectory Analysis and Causal Extraction for Agent Optimization](https://arxiv.org/abs/2607.07702v1)** `[hot,deep]`
  Structural Trajectory Analysis and Causal Extraction (arXiv 2607.07702) proposes a framework to filter noisy agent traces into root-cause diagnoses, enabling LLM optimizers to focus on high-value failures rather than overfitting to low-signal noise. Agent failure analysis is a bottleneck in production loops; systematizing root-cause extraction turns debugging into a repeatable process and a publishable artifact.
  Apply ▸ [micro-exp] Apply the structural trajectory filtering technique to a batch of failed agent runs and compare optimizer signal before/after filtering. — via **arXiv 2607.07702**
