## Papers worth a skim

- **[When Classic Cache Policies Fail: Learning-Augmented Replacement for Semantic Retrieval Buffers](https://arxiv.org/abs/2607.00394)** `[deep,high_value]`
  This paper formalizes semantic cache replacement as an online learning problem with continuous hit quality and switching costs. Experiments on MemoryBench show classic policies (LRU, LFU) fail; learned policies using similarity and access patterns outperform heuristics by 15–30%. Retrieval-buffer management is invisible but critical to multi-turn agent quality; this is the first rigorous treatment.
  Apply ▸ [read] Read §3–4 for the problem formulation, then inspect the MemoryBench LoCoMo/DialSim eval sets to design a similar cache-hit benchmark for your domain. — via **MemoryBench-Full dataset (LoCoMo, DialSim splits)**
- **[TurnOPD: Making On-Policy Distillation Turn-Aware for Efficient Long-Horizon Agent Training](https://arxiv.org/abs/2607.05804)** `[hot,deep,high_value]`
  TurnOPD introduces turn-level early stopping and KL reweighting for on-policy distillation of long-horizon agents. It trains only on high-value turns (discarding noisy tails) and concentrates supervision on trajectory branch-points, cutting wall-clock by 40% with higher task success. Agents running many-step tasks waste tokens on irrelevant rollouts; this is the first principled method to trim them during distillation.
  Apply ▸ [micro-exp] Reproduce the turn-importance estimator (Appendix B) on a simple SWE-bench trajectory dataset to see which turns carry signal. — via **TurnOPD paper (arxiv 2607.05804) + any SWE-bench trace logs**
- **[Hierarchical Sparse Attention Done Right: Toward Infinite Context Modeling](https://arxiv.org/abs/2607.02980)** `[hot,deep,high_value]`
  HiLS Attention is an end-to-end learned chunk-wise sparse attention that selects chunks via a hierarchical landmark mechanism trained under LM loss. It achieves full-attention quality on 1M+ contexts with sub-quadratic cost and strong extrapolation beyond training length. Learned chunk selection finally closes the accuracy gap of sparse attention, making infinite-context serving feasible without quadratic blow-up.
  Apply ▸ [read] Read §3.2 for the landmark-pruning algorithm and compare to Ring Attention or Mamba-style state compression for your next long-context prototype. — via **HiLS Attention paper (arxiv 2607.02980)**
- **[DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation](https://arxiv.org/abs/2607.05147)** `[hot,deep,high_value]`
  DSpark combines semi-autoregressive draft generation with a confidence-scheduled verifier that dynamically prunes low-confidence tokens before verification. It achieves 2–3× higher throughput than Medusa/EAGLE under batch serving by not wasting slots on doomed tokens. Batch-aware speculative decoding is the next frontier; this is the first paper to treat draft rejection as a batch-capacity problem.
  Apply ▸ [read] Read §4 for the confidence scheduler and §5 for batch-concurrency results; sketch a similar confidence estimator for your existing Medusa/EAGLE setup. — via **DSpark paper (arxiv 2607.05147) + any Medusa/EAGLE codebase**
- **[TREK: Distill to Explore, Reinforce to Refine](https://arxiv.org/abs/2607.05339)** `[hot,deep,high_value]`
  TREK uses teacher distillation not for imitation but to expand the student's exploration support on hard prompts where GRPO stalls. It consumes only verified trajectories (any verifier: unit tests, formal proof checkers) and alternates distillation with GRPO, yielding gains on SWE-bench and math reasoning. Shows how to break out of on-policy loops that get stuck; generalizes beyond RL-only training.
  Apply ▸ [micro-exp] Implement the staged loop (distill → GRPO → filter by verifier) on a small math-reasoning dataset (e.g., GSM8K with verification via sympy). — via **TREK paper (arxiv 2607.05339) + any GRPO trainer (e.g., TRL)**
- **[SIEVE: Structure-Aware Data Selection for Imitation Learning with VLA Models](https://arxiv.org/abs/2607.06442)** `[hot,high_value]`
  SIEVE is a structure-aware data selection method for VLA imitation learning that clusters demonstrations by reusable sub-behaviors (skills) and selects diverse coverage. It outperforms random and trajectory-level selection on OpenVLA by 15–20% success rate. Applies skill-clustering ideas from RL to data selection, a pattern transferable to any agent fine-tuning pipeline.
  Apply ▸ [read] Read §3 for the skill-clustering algorithm and adapt it to select diverse trajectories from your agent trace logs. — via **SIEVE paper (arxiv 2607.06442)**
