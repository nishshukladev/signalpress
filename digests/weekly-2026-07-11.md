TestEvo-Bench, UniClawBench, and SWE-Review offer multi-turn, closed-loop benchmarks that separate genuine capability from artifact. ### 2. Long-Horizon Agent Training: TREK, TurnOPD, CompactionRL, and Memory-as-Agent `[hot,deep,high_value]`

Four papers tackle the same bottleneck: standard RL stalls on long-horizon tasks because trajectories exceed context, rollouts fail completely on hard problems, and reward is too delayed. TREK uses teacher distillation for exploration, TurnOPD prunes low-value turns, CompactionRL learns to compress, and Proactive Memory agents separate memory from action. Each offers a distinct axis for scaling test-time compute and training compute in tandem.
Durability: **high** · Leverage: **high**

- [TurnOPD: Making On-Policy Distillation Turn-Aware for Efficient Long-Horizon Agent Training](https://arxiv.org/abs/2607.05804) (hf_papers)

### 3. KV Cache Optimization & Speculative Decoding: KVpop, DSpark, DominoTree, and Relaxed Spec-Decode `[hot,deep,high_value]`

KV cache growth remains the primary bottleneck in long-context inference. KVpop learns eviction policies from future attention; DSpark prunes doomed tokens before verification; DominoTree adds conditional tree-structured drafting; and the relaxed spec-decode paper maps the quality-speed Pareto frontier. Together they define the 2026 playbook for sub-quadratic autoregressive decoding.
Durability: **high** · Leverage: **high**

## Build-of-the-week

**Variance Decomposition Dashboard for SWE-Bench**

Build a reproducible variance decomposition dashboard for SWE-Bench (or TestEvo-Bench) that separates signal from noise using the OpenAI blog's statistical framework. Run 5+ seeds per model×task, compute per-task variance, and visualize where instability dominates. Ship as a Jupyter notebook + interactive dashboard (Streamlit or Flint) so practitioners can audit their own eval pipelines.

- Builds on: **SWE-Bench (princeton-nlp/SWE-bench), TestEvo-Bench (arxiv:2607.02469), OpenAI's 'Separating Signal from Noise' blog post, and Flint (microsoft.github.io/flint-chart) or Streamlit for visualization.**
- Prior art checked: Checked: OpenAI's blog provides the statistical framework but no code; SWE-Bench and TestEvo-Bench offer eval harnesses but no built-in variance decomposition; existing eval dashboards (e.g., lm-evaluation-harness) report single-run scores. No off-the-shelf tool combines multi-seed runs with per-task variance breakdowns.
- Result to publish: Median coefficient of variation (CV) across SWE-Bench tasks, with a ranked list of the 10 highest-variance tasks and their root causes (test brittleness, temperature sensitivity, or prompt formatting).
- Draft post title: *Variance Decomposition Dashboard for SWE-Bench: Separating Signal from Noise in Coding Agent Evals*
