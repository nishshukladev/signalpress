- **[OpenForgeRL: Train Harness-native Agents in Any Environment](https://arxiv.org/abs/2607.21557)** `[hot,deep,high_value]`
  OpenForgeRL provides an open framework to train agents end-to-end in complex multi-turn harnesses (like Claude Code or Codex) without requiring separate SFT/RL stacks. It unifies environment interaction and harness-based inference so that you can run policy-gradient RL directly on agents that use tool-calls, retries, and external APIs. Closes the training-deployment gap for production agent harnesses; lets you iterate on RL policies that match the exact multi-turn flows users see.
  Apply ▸ [weekend-build] Clone OpenForgeRL, adapt one of its example harnesses to your task environment, and run a short RL loop on a 7B model. — via **OpenForgeRL (arXiv 2607.21557, HF paper index 50)**

## Trending repos & tools

- **[Multi-Turn On-Policy Distillation with Prefix Replay](https://arxiv.org/abs/2607.04763)** `[hot,deep,high_value]`
  ReOPD (Replayed-Prefix On-Policy Distillation) enables cheaper multi-turn agent training by replaying pre-collected teacher trajectories and only querying the teacher at branch points, instead of rolling out the student in the full environment every update. The method retains on-policy guarantees while drastically cutting environment interaction costs. Practical technique to scale agent distillation when environment rollouts are expensive; bridges online RL and offline imitation learning.
  Apply ▸ [read] Read the ReOPD paper to understand the prefix-replay mechanism and compare with standard OPD and RLHF workflows. — via **arXiv 2607.04763 (Multi-Turn On-Policy Distillation with Prefix Replay)**
- **[Sample-Efficient Learning from Agent Experience](https://arxiv.org/abs/2607.21051)** `[hot,deep,high_value]`
  Sample-Efficient Learning from Agent Experience proposes context distillation for internalizing multi-turn interaction traces into model weights, letting agents retain lessons from their own rollouts without keeping them in-context. The method is far more sample-efficient than naive finetuning because it selectively distills high-value trajectories. Directly addresses the memory-bounded context problem for long-running agents; enables continual learning from agent experience at inference time.
  Apply ▸ [read] Read the paper and identify how to integrate trajectory selection and distillation into an existing agent training loop. — via **arXiv 2607.21051 (Sample-Efficient Learning from Agent Experience)**
- **[LLMs Get Lost in Evolving User Intent](https://arxiv.org/abs/2607.20734)** `[hot,deep,high_value]`
  LLMs Get Lost in Evolving User Intent introduces a benchmark and analysis showing that state-of-the-art LLMs fail to track user intent as it shifts across multi-turn conversations—users rarely specify goals upfront and instead revise them iteratively. The work proposes evaluation protocols that measure intent-tracking fidelity in realistic collaborative settings. Exposes a gap in how we eval and train agents: most benchmarks assume static, fully-specified tasks, but real users refine goals on the fly.
  Apply ▸ [micro-exp] Replicate the intent-shift eval protocol on your own agent; measure how often it persists with stale goals after user corrections. — via **arXiv 2607.20734 (LLMs Get Lost in Evolving User Intent)**
- **[MIRROR: Learning from the Other View for Multi-Modal Reasoning](https://arxiv.org/abs/2607.21552v1)** `[hot,deep]`
  MIRROR (Learning from the Other View for Multi-Modal Reasoning) shows that VLMs succeed on text-only geometry problems but fail on diagram-only versions, and vice versa—revealing inconsistent reasoning across modalities. The paper proposes cross-view alignment training to make models reason consistently whether the input is text, image, or both. Highlights a failure mode in vision-language reasoning that standard benchmarks miss; cross-view alignment improves robustness and is a technique you can apply to any VLM finetuning.
  Apply ▸ [read] Read MIRROR to understand how to construct text/image/combined eval splits and apply cross-view consistency loss during training. — via **arXiv 2607.21552 (MIRROR)**
- **[FinanceComplexQA: Benchmarking Agentic Reasoning on Industrial-grade Financial Documents](https://arxiv.org/abs/2607.19238)** `[hot,high_value]`
  FinanceComplexQA is a new benchmark of 2,000 industrial-grade financial documents with complex layouts (tables, charts, formulas) requiring agentic multi-hop reasoning. It was generated via a LaTeX synthesis workflow driven by domain experts, and it reveals large performance gaps between current agent systems. Provides a realistic testbed for document agents in a high-stakes vertical; the LaTeX synthesis method is reusable for other document-heavy domains.
  Apply ▸ [micro-exp] Download FinanceComplexQA from Hugging Face and run your document agent against it to measure multi-hop accuracy and tool-use patterns. — via **FinanceComplexQA (arXiv 2607.19238, HF paper index 54)**
- **[Marimo now runs in PyCharm](https://marimo.io/blog/pycharm)** `[hot,high_value]`
  Marimo, the reactive Python notebook, now runs as an embedded plugin inside PyCharm. This brings live dataflow reactivity and reproducible notebooks into a full IDE, eliminating the Jupyter server/kernel split and making notebook-based prototyping a first-class PyCharm workflow. Bridges the gap between exploratory notebook work and production IDE tooling; especially valuable for AI engineers iterating on prompts, evals, and model outputs.
  Apply ▸ [micro-exp] Install the Marimo PyCharm plugin, open a .py notebook, and convert one of your existing Jupyter eval scripts to reactive mode. — via **Marimo PyCharm plugin (marimo.io/blog/pycharm)**
- **[Nativ: Run AI models locally on your Mac](https://simonwillison.net/2026/Jul/21/nativ/#atom-everything)** `[hot]`
  Nativ is a new macOS desktop application for running vision-LLMs locally via MLX, wrapping the excellent MLX-VLM library in a full chat UI and localhost API server. It offers a polished LM-Studio-like experience with native Mac performance and on-device inference. Lowers the barrier to running vision models on Apple Silicon; useful for rapid prototyping and offline demos without cloud dependencies.
  Apply ▸ [micro-exp] Download Nativ for macOS, load a vision model, and test its localhost API against your existing LLM tooling. — via **Nativ (blaizzy.github.io/nativ)**

## Papers worth a skim

- **[Predictive Divergence Masks for LLM RL](https://arxiv.org/abs/2607.10848)** `[deep,high_value]`
  Predictive Divergence Masks for LLM RL replaces PPO's ratio-based trust region with a probability-divergence criterion that better measures when a policy has moved too far. It improves off-policy sample efficiency and stability by catching distribution shifts that importance ratios miss. Directly applicable to RLHF/RLAIF pipelines; a drop-in improvement over standard PPO clipping for any lab running LLM fine-tuning.
  Apply ▸ [read] Read the paper and compare the divergence-based mask with your current PPO implementation; note the API changes needed to adopt it. — via **arXiv 2607.10848 (Predictive Divergence Masks for LLM RL)**
