## Papers worth a skim

- **[GradCuit: Credit-Assigned Gradient Flow Enables Robust and Interpretable Test-Time Latent Reasoning](https://arxiv.org/abs/2608.02585v1)** `[deep,high_value]`
  GradCuit inserts optimizable latent states at selected token positions and backpropagates credit assignment through the reasoning circuit. Enables instance-specific test-time optimization with interpretable gradient flow. Learn a new test-time reasoning paradigm that goes beyond decode-then-optimize by gradients through latent reasoning paths.
  Apply ▸ [read] Read GradCuit paper (2608.02585), reproduce the toy latent-state insertion on a 7B model with a multi-hop QA task, measure credit-assignment improvement vs. vanilla chain-of-thought. — via **arxiv.org/abs/2608.02585**
- **[Structured Memory for Edge Language Models: Persistent Context and Corpus Retrieval via O(1) SSM State Injection](https://arxiv.org/abs/2608.02560v1)** `[deep,high_value]`
  PRECOG collapses RAG prefill from O(L_context) to O(1) by pre-computing SSM recurrent states and injecting them per query. Eliminates prefill latency for SSM-based language models serving long contexts. Understand how to exploit SSM state structure for constant-time context injection in production RAG systems.
  Apply ▸ [read] Read PRECOG paper (2608.02560), implement a minimal pre-computed state cache for Mamba or StripedHyena on a 1k-doc corpus, measure prefill speedup vs. naive concat. — via **arxiv.org/abs/2608.02560**
- **[Uncertainty Is Not Enough: Value-of-Information Routing for Mixtures of LoRA Experts](https://arxiv.org/abs/2608.02528v1)** `[deep,high_value]`
  Value-of-Information routing for LoRA mixtures only activates additional experts if they reduce expected loss, not merely uncertainty. Formalizes routing as certified VoI allocation with provable bounds. Learn to route MoE or LoRA experts by expected value rather than heuristic uncertainty thresholds.
  Apply ▸ [read] Read VoI routing paper (2608.02528), implement the VoI allocation rule on a toy 2-expert LoRA mixture, compare expert selection vs. uncertainty-based routing on a held-out task. — via **arxiv.org/abs/2608.02528**
- **[LiveMem: Maintaining Memory State Continuity in Long-Running LLM Inference](https://arxiv.org/abs/2608.02515v1)** `[hot,deep,high_value]`
  LiveMem maintains a persistent memory state across context windows, enabling continuous state evolution independent of active context turnover. Formalizes state continuity under fixed-capacity memory for long-running agents. Understand how to architect stateful inference for assistants that outlive their context window.
  Apply ▸ [read] Read LiveMem paper (2608.02515), design a minimal stateful memory layer using an SSM or external KV store, benchmark state retention vs. naive summarization on a multi-session dialogue corpus. — via **arxiv.org/abs/2608.02515**
- **[SWE-Touch: Benchmarking Coding Agents When Users Touch the Code](https://arxiv.org/abs/2608.02499v1)** `[hot,deep,high_value]`
  SWE-Touch introduces Counter-Edits: plausible user code changes injected mid-task to test whether coding agents can parse and respond to shared-workspace modifications. First benchmark for human-in-the-loop code collaboration. Eval framework for real-world coding-agent collaboration where users touch code mid-flight.
  Apply ▸ [micro-exp] Clone SWE-Touch repo, run the Counter-Edit suite on your current coding agent, measure recovery rate vs. SWE-bench baseline, document failure modes. — via **arxiv.org/abs/2608.02499**
- **[RecHarness: A Bandit-Routed Agentic Harness for Self-Evolving Recommender Systems](https://arxiv.org/abs/2607.29241)** `[hot,high_value]`
  RecHarness uses a bandit router to select modification strategies for recommender models, separating direction selection from hypothesis generation. Automated recommender optimization harness with trial budget allocation. Learn bandit-driven hyperparameter and architecture search patterns for ML systems beyond LLMs.
  Apply ▸ [read] Read RecHarness paper (2607.29241), adapt the bandit router pattern to your own hyperparameter search, log regret vs. grid search on a small dataset. — via **arxiv.org/abs/2607.29241**
- **[LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks](https://arxiv.org/abs/2608.01964)** `[hot,deep,high_value]`
  LongHorizon-Harness separates task execution, task state, and completion assessment into explicit components, preventing incorrect self-assessment from propagating. Reformulates long-horizon agent execution as task-state management. Architectural pattern for robust long-horizon agent execution with external state tracking.
  Apply ▸ [read] Read LongHorizon-Harness paper (2608.01964), implement a minimal external state tracker for a multi-step agent task (e.g. multi-file code refactor), compare task completion accuracy vs. in-context state. — via **arxiv.org/abs/2608.01964**
