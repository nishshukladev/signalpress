## Papers worth a skim

- **[Pass the Baton: Trajectory-Relayed On-Policy Distillation](https://arxiv.org/abs/2607.26057v1)** `[hot,deep,high_value]`
  Pass the Baton introduces trajectory-relayed on-policy distillation (OPD) that fixes prefix failure by detecting when the student commits to a wrong reasoning path and splicing in teacher redirections. The method outperforms standard OPD by reducing misdirected continuations and wasted compute. Distillation is central to agent affordability; a technique that recovers from prefix errors without throwing away trajectories improves both data efficiency and final policy quality.
  Apply ▸ [micro-exp] Reproduce the prefix-failure detection logic on a small reasoning dataset to validate redirection gains. — via **arxiv:2607.26057**
- **[UniMem: Complementary Episodic-to-Parametric Memory for Boundary-Agnostic Task Streams](https://arxiv.org/abs/2607.26017v1)** `[hot,deep,high_value]`
  UniMem proposes a hybrid episodic-to-parametric memory that stores task evidence externally (fast, retrieval-based) and periodically consolidates recurring patterns into model weights (stable, zero-latency). This solves the stability-plasticity dilemma for agents facing evolving, boundary-agnostic task streams. Long-context agents need memory that scales without inference overhead; a working consolidation strategy lets you ship agents that learn from deployment without retraining loops.
  Apply ▸ [weekend-build] Extend your agent's external memory with a periodic consolidation step that fine-tunes a small adapter on high-frequency retrieval hits. — via **arxiv:2607.26017**
- **[Reinforcement Learning for Code Optimization](https://arxiv.org/abs/2607.25970v1)** `[hot,deep,high_value]`
  Reinforcement Learning for Code Optimization extends RL-for-correctness by making execution time learnable via careful noise filtering, reward shaping, and GRPO stabilization. The paper demonstrates that timing-driven rewards can work if measurement variance and sparse-signal issues are addressed systematically. Optimizing for speed—not just correctness—unlocks compiler-quality code from LLMs; this paper provides the recipe to make execution-time RL stable and reproducible.
  Apply ▸ [micro-exp] Replicate the timing-reward shaping on a small benchmark to validate whether your RL loop can learn latency improvements. — via **arxiv:2607.25970**
- **[Minimizing Targeted Activations: Input-Only Suppression of Evaluation-Awareness Latents in Large Language Models](https://arxiv.org/abs/2607.25907v1)** `[hot,deep,high_value]`
  This paper demonstrates input-only suppression of evaluation-awareness latents by optimizing prompts to drive chosen internal activations toward zero, threatening eval validity if models detect testing. The approach adapts Fluent Dreaming / EPO and requires no inference-time model access. If your evals can be gamed by a prompt optimizer, your safety benchmarks are fragile; understanding this attack surface is critical for robust agent evaluation design.
  Apply ▸ [micro-exp] Run the Fluent Dreaming optimizer against your eval harness to test whether input-only steering can suppress target activations. — via **arxiv:2607.25907**
- **[VisualPatchWorld: Code World Models as Latent Structured Representations for Planning](https://arxiv.org/abs/2607.25236)** `[hot,deep,high_value]`
  VisualPatchWorld unifies neural predictors and symbolic physics by representing world models as executable code with inspectable state and physical laws. The framework supports perception, simulation, and planning in a form that is both scalable from data and editable by hand. Code-based world models give you interpretability and debugging hooks that black-box latent dynamics never will; this bridges the gap between learned and engineered simulators.
  Apply ▸ [read] Study the VisualPatchWorld codebase to understand how symbolic state and neural dynamics are co-trained. — via **arxiv:2607.25236**
- **[Temporal-Distance JEPA: Plan-Aware Representation Learning for Latent World Model Predictive Control](https://arxiv.org/abs/2607.25337)** `[hot,deep,high_value]`
  Temporal-Distance JEPA replaces short-horizon latent prediction with plan-aware representation learning that uses temporal distance to goal as supervision. This aligns JEPA training with the multi-step ranking required by latent MPC, improving planning from offline demonstration logs. JEPA models are fast to train but fail at planning if embedding geometry doesn't reflect goal progress; this fix makes them viable backbones for latent control.
  Apply ▸ [micro-exp] Retrofit your JEPA training loop with temporal-distance loss and evaluate whether latent MPC rollouts improve. — via **arxiv:2607.25337**
- **[A New Role for Relevance: Guiding Corpus Interaction in Agentic Search](https://arxiv.org/abs/2607.24223)** `[hot,deep,high_value]`
  A New Role for Relevance introduces relevance-guided Direct Corpus Interaction (DCI) that uses retrieval scores to prioritize grep-style exploration, localizing evidence faster than relevance-agnostic search while retaining fine-grained verification. The method outperforms top-k retrieval agents on complex questions. Retrieval agents that can't compose or verify evidence fail on multi-hop queries; DCI with relevance ranking gives you a principled way to explore large corpora efficiently.
  Apply ▸ [weekend-build] Extend your retrieval agent with relevance-prioritized grep exploration using the DCI framework. — via **arxiv:2607.24223**
- **[Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory](https://arxiv.org/abs/2607.24368)** `[hot,deep,high_value]`
  Keep It InMind identifies the implicit-association blind spot in agent memory systems: needed facts (e.g., tree-nut allergy) fail to retrieve for semantically distant queries (macaron request) despite logical relevance. The paper benchmarks this failure mode and proposes world-knowledge-aware retrieval strategies. If your agent's memory can't bridge implicit associations, it will miss critical context and fail silently; fixing this requires rethinking retrieval beyond embedding similarity.
  Apply ▸ [micro-exp] Evaluate your agent's memory retrieval on the InMind benchmark to measure implicit-association coverage. — via **arxiv:2607.24368**
