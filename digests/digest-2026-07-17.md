- **[MedFailBench: A Clinician-Built Open-Source Benchmark for Medical AI Safety Boundary Inspection](https://arxiv.org/abs/2607.15166v1)** `[hot,high_value]`
  MedFailBench is a clinician-built synthetic benchmark and failure atlas that labels medical AI errors by severity (1–5) and safety gate type (missed escalation, unsafe dosing, etc.). V0.2.1 contains 44 clinician-reviewed cases with public failure labels, enabling systematic safety boundary inspection beyond binary pass/fail. Structured failure taxonomies are emerging as best practice for high-stakes AI evals; this benchmark offers a concrete, reusable pattern for safety-gate labeling.
  Apply ▸ [micro-exp] Clone MedFailBench, run your model against the v0.2.1 cases, and produce a failure-type breakdown for one safety gate. — via **MedFailBench (arXiv:2607.15166 / GitHub)**
- **[Smarter and Cheaper at Once: Byte-Exact KV-Cache Grafting Turns a Frozen Small Model into a Verified-Knowledge Flywheel](https://arxiv.org/abs/2607.14431)** `[hot,high_value]`
  This repo demonstrates byte-exact KV-cache grafting: depositing verified knowledge as a KV-state artifact once, then restoring it into a fresh inference context later, with zero KL divergence and 100% argmax agreement. The graft is deterministic (SHA-256 equality), enabling both capability gains and dramatic cost reduction by skipping redundant prefill. If you serve a model with repeated, verified prefixes (e.g., system prompts, few-shot examples), cache grafting can cut latency and cost while preserving determinism.
  Apply ▸ [micro-exp] Clone the KV-cache grafting repo (arXiv:2607.14431 / GitHub), generate a cached artifact for a fixed prefix, and verify byte-exact restore. — via **KV-cache grafting repo (arXiv:2607.14431)**

## Dev-experience & practices

  Pydantic's lead writes that the "human-in-the-loop is tired" and proposes shifting from manual review gates to automated confidence thresholds and audit trails. The post names design patterns (threshold-gated automation, structured logging for post-hoc review) that align with how strong teams are moving beyond per-request approvals. Adopting confidence-scored automation over blocking approval loops unlocks higher agent throughput while preserving traceability—a practice gaining traction in production AI systems.

- **[Demystifying On-Policy Distillation: Roles, Pathologies, and Regulations](https://arxiv.org/abs/2607.13399)** `[hot,deep,high_value]`
  This paper clarifies on-policy distillation (OPD) as an exploration catalyst—steering students toward correct reasoning paths via dense token-level guidance—and identifies pathologies (mode collapse, prompt-diversity sensitivity). The authors propose regulations (prompt diversity over per-problem sampling, spectral regularization) that improve OPD stability. OPD is increasingly used for post-training reasoning models; understanding its failure modes and mitigations will help you avoid wasted compute and unstable training.
  Apply ▸ [read] Read Demystifying OPD (arXiv:2607.13399), audit a distillation run for prompt diversity, and test one proposed regulation. — via **arXiv:2607.13399 paper**

## Papers worth a skim

- **[RoboTTT: Context Scaling for Robot Policies](https://arxiv.org/abs/2607.15275v1)** `[hot,deep,high_value]`
  RoboTTT scales robot visuomotor context to 8K timesteps (three orders of magnitude beyond prior policies) via test-time training, unlocking one-shot in-context imitation from human video and on-the-fly policy improvement. The paper demonstrates context-scaling techniques that generalize beyond robotics to long-horizon agent reasoning. Long-context test-time training is a transferable pattern for agents that need persistent memory and in-context adaptation without full retraining.
  Apply ▸ [read] Read RoboTTT (arXiv:2607.15275), map the test-time training loop to a non-robotics agent task you own, and sketch a micro-experiment. — via **RoboTTT paper (arXiv:2607.15275)**
- **[Bridge Evidence: Static Retrieval Utility Does Not Predict Causal Utility in Multi-Step Agentic Search](https://arxiv.org/abs/2607.15253v1)** `[hot,deep,high_value]`
  "Bridge Evidence" argues that static retrieval utility (answer-improvement on a single document) does not predict causal utility in multi-step agentic search, because a document's value often lies in what the agent can do next. The paper measures the gap and proposes training/eval methods that optimize for agentic trajectories, not single-turn relevance. Rethinking retrieval for agents—rather than one-shot QA—will become critical as you build systems where evidence compounds across turns; this paper names the problem and solution.
  Apply ▸ [read] Read Bridge Evidence (arXiv:2607.15253), audit one retrieval pipeline for "next-step utility," and prototype a causal-utility scorer. — via **Bridge Evidence paper (arXiv:2607.15253)**
- **[In-Place Tokenizer Expansion for Pre-trained LLMs](https://arxiv.org/abs/2607.15232v1)** `[hot,deep,high_value]`
  This paper presents "in-place tokenizer expansion" for compact pre-trained LLMs: expanding vocabulary for under-represented languages without retraining the full model, by re-initializing embedding/LM-head layers while preserving the rest. On compact models (where embedding overhead is significant), this can reduce latency and energy for newly-targeted languages. If you serve a compact model to multiple language regions, this technique lets you add vocabulary post-training with minimal overhead—relevant for edge and efficiency-constrained deployments.
  Apply ▸ [read] Read In-Place Tokenizer Expansion (arXiv:2607.15232), identify a compact model you serve, and estimate embedding/LM-head overhead for a target language. — via **arXiv:2607.15232 paper**
- **[T^2MLR: Transformer with Temporal Middle-Layer Recurrence](https://arxiv.org/abs/2607.15178v1)** `[hot,deep]`
  T²MLR introduces Transformers with Temporal Middle-Layer Recurrence: fusing a cached middle-layer representation from the previous token into an earlier layer of the current token, enabling abstract reasoning states to persist across time without repeated token-space compression. This architectural pattern trades autoregressive bottleneck for richer inter-token state. Understanding recurrence-in-transformer architectures clarifies emerging alternatives to pure autoregressive decoding, with implications for latency-sensitive reasoning workloads.
  Apply ▸ [read] Read T²MLR (arXiv:2607.15178), compare latency/memory to standard transformer decoding, and assess applicability to a reasoning-heavy task you own. — via **T²MLR paper (arXiv:2607.15178)**
- **[GRASP: GRanularity-Aware Search Policy for Agentic RAG](https://arxiv.org/abs/2607.10463)** `[hot,deep,high_value]`
  GRASP introduces a reinforcement-learning framework for training granularity-aware search policies in agentic RAG: deciding when to retrieve, whether to use lexical or semantic search, and how to control context granularity to avoid irrelevant tokens interfering with agent reasoning. The paper demonstrates policy learning that outperforms static retrieval heuristics. As agentic RAG moves beyond fixed retrieval schedules, learned search policies become a lever for latency and accuracy—this paper provides a training recipe.
  Apply ▸ [read] Read GRASP (arXiv:2607.10463), identify a static retrieval decision in your agent, and sketch an RL policy to replace it. — via **GRASP paper (arXiv:2607.10463)**
- **[SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning](https://arxiv.org/abs/2607.14777)** `[hot,deep,high_value]`
  SEED (Self-Evolving On-Policy Distillation) addresses the sparse trajectory-level reward problem in agentic RL by iteratively distilling intermediate reasoning traces from an on-policy teacher, closing the supervision gap between episode outcomes and token-level policy learning. The paper demonstrates gains on long-horizon tasks involving tool use and environment feedback. Closing the reward-sparsity gap is critical for training agents on multi-turn tasks; SEED offers a concrete recipe for self-evolving distillation that you can adapt.
  Apply ▸ [read] Read SEED (arXiv:2607.14777), map the self-evolving distillation loop to an agent task you own, and prototype one iteration. — via **SEED paper (arXiv:2607.14777)**

## Pattern watch

**DEEP pattern**: Long-context test-time training (RoboTTT 8K timesteps), recurrent middle-layer fusion (T²MLR), and KV-cache grafting all converge on *persistent state across decoding steps*—moving beyond autoregressive token bottlenecks. **HOT + HIGH-VALUE**: Four papers (GRASP, Bridge Evidence, SEED, OPD) independently address the *supervision gap in agentic RL*—static retrieval/eval metrics fail multi-turn reasoning, and token-level distillation is emerging as the practical fix. **PRACTICES**: "Human-in-the-loop is tired" + OPD clarity signal a shift from manual gates to *confidence-scored automation with audit trails*.
