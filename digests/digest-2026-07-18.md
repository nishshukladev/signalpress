## Papers worth a skim

- **[Partition, Prompt, Aggregate: Statistical Self-Consistency in Language Models](https://arxiv.org/abs/2607.15277v1)** `[deep,high_value]`
  Partition, Prompt, Aggregate proposes treating LLM in-context learning as conditional inference and tests whether model estimates satisfy the law of total probability over valid population partitions. Practical framework to diagnose calibration and evaluate statistical consistency in agent decision-making. Helps you build agents with probabilistically sound confidence intervals and testable statistical guarantees.
  Apply ▸ [micro-exp] Instrument your agent's multi-sample prompts to verify that marginal aggregation holds; report divergence as a debug metric. — via **arxiv:2607.15277 and any existing eval harness (e.g., inspect_ai)**
- **[Mask-Aware Policy Gradients for Diffusion Language Models](https://arxiv.org/abs/2607.15200v1)** `[deep,high_value]`
  Mask-Aware Policy Gradients extends RL to Masked Diffusion Language Models by modeling both token and unmasking-order decisions at each denoising step. Addresses the log-likelihood intractability that blocks standard policy-gradient methods for diffusion LMs. Equips you to apply RL fine-tuning to diffusion-based text models; unlocks a new axis for reasoning improvement.
  Apply ▸ [read] Compare this masking-aware gradient estimator against vanilla PPO on your MDLM fine-tuning task. — via **arxiv:2607.15200 + huggingface/diffusers**
- **[Rethinking the Evaluation of Harness Evolution for Agents](https://arxiv.org/abs/2607.12227)** `[hot,deep,high_value]`
  Rethinking the Evaluation of Harness Evolution shows that harness-evolution methods (which iteratively search over agent scaffolding) should be benchmarked against test-time compute scaling baselines, not static prompts. Exposes a protocol gap: evolving harnesses on public test sets inflates reported gains. Prevents you from wasting GPU cycles on harness search when simple test-time scaling yields the same lift.
  Apply ▸ [micro-exp] Re-baseline your harness evolution experiments against iterative refinement (e.g., best-of-N, self-consistency) on a held-out split. — via **arxiv:2607.12227 + inspect_ai or any agent eval suite**
- **[BadWAM: When World-Action Models Dream Right but Act Wrong](https://arxiv.org/abs/2607.15207v1)** `[hot,deep,high_value]`
  BadWAM introduces a unified framework for backdoor attacks on world-action models—models that couple action generation with future-world prediction. Shows that a WAM can hallucinate plausible futures while executing unsafe actions, breaking the interpretability/safety assumption. Critical red-team methodology if you deploy world-model-based agents; informs robustness evals for embodied AI.
  Apply ▸ [read] Adapt the BadWAM threat model to construct adversarial test cases for your world-model agent; measure action-world alignment divergence. — via **arxiv:2607.15207 + your existing world-action model checkpoints**
- **[LongStraw: Long-Context RL Beyond 2M Tokens under a Fixed GPU Budget](https://arxiv.org/abs/2607.14952)** `[hot,deep,high_value]`
  LongStraw is an architecture-aware execution stack enabling million-token RL post-training under a fixed GPU budget. Bridges the gap between inference context lengths (approaching 1M) and typical RL workloads stuck at 256K, critical for AI agents with long-horizon tool/document/observation sequences. Unlocks RL fine-tuning for agentic workloads with massive context; directly supports Staff+-level long-context optimization.
  Apply ▸ [weekend-build] Profile your RL training loop with LongStraw's execution plan; benchmark memory/throughput against your baseline setup. — via **arxiv:2607.14952 + existing RL frameworks (e.g., TRL)**
- **[DeepLoop: Depth Scaling for Looped Transformers](https://arxiv.org/abs/2607.13491)** `[deep,high_value]`
  DeepLoop formalizes the residual-scaling problem unique to looped Transformers (recurrent weight-sharing architectures) and proposes a gradient-aware scaling scheme. Shows that shared parameter updates across multiple rounds change the effective learning rate per unrolled block. Actionable depth-scaling recipe for recurrent/looped architectures; useful if you're pushing test-time compute with loop unrolling.
  Apply ▸ [micro-exp] Instrument your looped transformer training to track per-round gradient norms; apply DeepLoop's scaling correction. — via **arxiv:2607.13491 + your existing transformer codebase**
- **[Spectral Rewiring for Exploration, Purification, and Model Merging](https://arxiv.org/abs/2607.03065)** `[hot,deep,high_value]`
  Spectral Rewiring shows that reasoning-effective RL updates concentrate in the spectral space of the base model; proposes low-rank spectral projection to preserve reasoning while merging multi-domain capabilities. Addresses premature test-time scaling saturation and interference in multi-task post-training. Named practice for preserving reasoning under RL fine-tuning; directly supports multi-domain agent deployments.
  Apply ▸ [weekend-build] Decompose your RL checkpoint into spectral components; merge domain-specific adaptations via spectral rewiring and benchmark test-time scaling curves. — via **arxiv:2607.03065 + huggingface/peft**
