## Papers worth a skim

- **[Explorative modeling: Train on the best of K guesses](https://alexiglad.github.io/blog/2026/explorative_modeling/)** `[deep,high_value]`
  Explorative modeling trains a model to predict the best of K random guesses at each step instead of a single next token, unlocking a "third pretraining axis" beyond scale and data. The author shows early evidence that this approach can improve generation quality by teaching the model to explore multiple hypotheses during training. Understanding training-time search (beyond test-time compute) may inform your next model fine-tuning or pretraining recipe; this is an emerging research direction.
  Apply ▸ [micro-exp] Reproduce the K-best training loop on a small dataset using the author's reference implementation to see if it lifts downstream task performance. — via **alexiglad/explorative_modeling**
- **[Beyond Geometric Complementarity: Coherent Overlap in Sparse Mixture-of-Experts Routing](https://arxiv.org/abs/2607.28308)** `[deep,high_value]`
  This paper proposes an Expert Subspace Separation Index (ESSI) to measure whether co-selected experts in sparse MoE models contribute distinct representation directions, and uses frozen-route interventions to isolate the value of routing coherence. Findings suggest that geometric complementarity alone does not explain MoE gains; candidate quality and context interactions matter. If you're tuning or deploying sparse MoE models, understanding *why* routing works helps you debug poor expert utilization and design better routing strategies.
  Apply ▸ [read] Compute ESSI for your deployed MoE model to identify whether experts are geometrically redundant and whether routing is actually selecting diverse subspaces. — via **arxiv:2607.28308 reference implementation**
- **[INTACT: Isomorphic Intent-to-Action Learning for Search-Free World Models](https://arxiv.org/abs/2607.26056)** `[deep,high_value]`
  INTACT (INtent-To-ACTion) is an end-to-end JEPA that learns to map deployment intent (goal state minus current state) directly to actions, avoiding expensive test-time search in forward world models. It uses an isomorphic architecture for local and goal motion-intent backbones with action-labeled trajectories. For robotics or goal-conditioned agents, learning intent-to-action mappings offline can replace costly planning loops at deployment; this shows how to structure the training problem.
  Apply ▸ [weekend-build] Implement the INTACT forward-inverse training loop on a simple goal-reaching dataset (e.g., Gym robotics) and measure whether it eliminates test-time search overhead. — via **arxiv:2607.26056 INTACT**
- **[Explorative Modeling: Unlocking a Third Pretraining Axis and End-to-End Generation](https://arxiv.org/abs/2607.27372)** `[deep,high_value]`
  Explorative Modeling proposes training on the best of K guesses per step to unlock end-to-end generation without factoring the problem into hand-designed stages. The paper argues this is a third pretraining axis (beyond scale and data) and shows early evidence that it improves sample quality in generative tasks. Training-time search may become a new lever for improving generative model quality; understanding this approach early positions you to apply it in your next fine-tuning or pretraining run.
  Apply ▸ [micro-exp] Reproduce the K-best training loop on a small generative modeling task using the author's reference implementation to see if it lifts quality. — via **arxiv:2607.27372 reference code**
- **[Beyond Borrowed Histories: Person-Aligned User Simulation for Interactive Role-Playing Evaluation](https://arxiv.org/abs/2607.27816)** `[deep,high_value]`
  This paper introduces person-aligned user simulation for role-playing agent evaluation, where an LLM-based user persona is instantiated from real user preferences and conversation history to generate interactive test dialogues. This replaces static fixed-history continuations and provides a more realistic, user-centric eval loop. If you're building or evaluating conversational agents, person-aligned simulation lets you generate eval data that reflects actual user preferences, improving eval reliability.

  AISPA (Artificial Intelligence System Prompt Assurance) is a user-centric framework for systematically auditing system prompts in AI applications. It examines specific behavioral promises, instruction coherence, and discrepancies between stated and actual model behavior, addressing the accountability gap in commercial AI products. If you're shipping AI products, auditing system prompts for consistency and safety claims is becoming a compliance requirement; this framework shows you how to structure the audit.
