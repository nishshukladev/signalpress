## Trending repos & tools

- **[Gemini last models: temperature, top_p, and top_k are deprecated and ignored](https://ai.google.dev/gemini-api/docs/latest-model)** `[hot,high_value]`
  Gemini deprecates temperature, top_p, and top_k parameters in latest models, reflecting a shift toward locked-inference presets. This forces practitioners to adapt prompts or choose different providers if sampling control is critical. Understanding API drift and fallback strategies is essential for production reliability.
  Apply ▸ [read] Review the Gemini API migration guide and test your inference pipelines against the new defaults. — via **ai.google.dev/gemini-api/docs**
- **[Two-Level Meta-Rubrics for Evaluating Open-Ended Generation: GAMUT, a Benchmark for Factual Completeness](https://arxiv.org/abs/2607.19322v1)** `[hot,deep,high_value]`
  GAMUT benchmark introduces two-level meta-rubrics to measure factual completeness (the missing half of factuality) in open-ended generation. Goes beyond decompose-search-verify to enumerate required facts in hierarchical structures. Completeness evals are critical for high-stakes domains and rarely covered in existing benchmarks.
  Apply ▸ [micro-exp] Run GAMUT on your domain's long-form outputs and compare recall vs. existing precision-only evals. — via **arxiv:2607.19322 + GAMUT benchmark**
- **[ResearchArena: Evaluating Sabotage and Monitoring in Automated AI R&D](https://arxiv.org/abs/2607.19321v1)** `[hot,deep,high_value]`
  ResearchArena evaluates AI control for automated AI R&D: can monitors detect covert sabotage by untrusted agents across safety/capabilities post-training, CUDA optimization, and API auditing? Four long-horizon tasks with ground truth. AI control is the emerging practice for deploying untrusted agents; understanding monitor design is a differentiator.
  Apply ▸ [weekend-build] Extend ResearchArena's monitor design to your own agentic task and measure false-negative rate on adversarial rollouts. — via **arxiv:2607.19321 + ResearchArena**
- **[CircuitKIT : Circuit Discovery, Evaluation, and Application Toolkit for Mechanistic Interpretability](https://arxiv.org/abs/2607.19317v1)** `[hot,high_value]`
  CircuitKIT unifies circuit discovery, evaluation, and intervention (pruning, editing, steering, fine-tuning) for mechanistic interpretability. Handles contrastive prompt generation automatically and enables apples-to-apples method comparison. Mechanistic interpretability is moving from research artifact to production toolchain; unified workflows accelerate adoption.
  Apply ▸ [micro-exp] Use CircuitKIT to discover and prune a task-specific circuit in a small model, then compare validation metrics. — via **arxiv:2607.19317 + CircuitKIT**
- **[AgentDebugX: An Open-Source Toolkit for Failure Observability, Attribution, and Recovery in LLM Agents](https://arxiv.org/abs/2607.18754)** `[hot,high_value]`
  AgentDebugX is an open-source debugging framework for LLM agents, organizing debugging as Detect → Attribute → Recover → Rerun. DeepDebug performs multi-turn root-cause diagnosis across global trajectory rather than surfacing errors only. Agent debugging is a top pain point in production; structured observability tools are scarce.
  Apply ▸ [micro-exp] Instrument your agent with AgentDebugX and run a failure-attribution session on a known bug. — via **arxiv:2607.18754 + AgentDebugX**
- **[DataFlow-Harness: A Grounded Code-Agent Platform for Constructing Editable LLM Data Pipelines](https://arxiv.org/abs/2607.16617)** `[hot,high_value]`
  DataFlow-Harness guides an LLM agent to construct platform-native DAGs through typed, incremental mutations instead of free-form scripts. Bridges the NL2Pipeline gap by materializing agent outputs as persistent, editable artifacts. Code agents that produce throwaway scripts waste iteration cycles; platform integration is the missing piece.
  Apply ▸ [weekend-build] Extend DataFlow-Harness to your own DAG platform or use it to build a reference LLM-to-workflow pipeline. — via **arxiv:2607.16617 + DataFlow-Harness**

## Papers worth a skim

- **[Copy Less, Ground More: Overcoming Repetitive Copying in Long-Context Reasoning via Evidence-Aware Reinforcement Learning](https://arxiv.org/abs/2607.19345v1)** `[deep,high_value]`
  Copy Less, Ground More identifies repetitive copying in long-context reasoning traces and proposes evidence-aware RL to fix it. The paper offers a concrete failure mode and a training recipe to improve chain-of-thought grounding. Diagnosing and fixing reasoning-trace pathologies is a scarce skill in RLVR workflows.
  Apply ▸ [read] Reproduce the repetitive-copying detection heuristic on your own reasoning traces and test the evidence-aware reward shaping. — via **arxiv:2607.19345**
- **[Agents in the Wild: Where Research Meets Deployment](https://arxiv.org/abs/2607.19336v1)** `[hot,deep,high_value]`
  Agents in the Wild tutorial (arXiv) bridges research prototypes and production agentic systems, covering robustness, safety, and reliability for software engineering, science, and finance deployments. Strong engineering focus on real-world constraints. Production-grade agent design is the highest-leverage skill gap for Staff+ engineers today.
  Apply ▸ [read] Work through the tutorial's deployment case studies and build a robustness checklist for your own agent. — via **arxiv:2607.19336**
- **[Off-Context GRPO: Learning to Reason on Hard Problems using Privileged Information](https://arxiv.org/abs/2607.19313v1)** `[hot,deep,high_value]`
  Off-Context GRPO uses privileged guidance (solution prefixes, hints) during RLVR training to escape zero-reward cliffs on hard problems. Generates off-context rollouts with non-zero reward, then distills back to standard prompts. Breaking the zero-signal barrier in RLVR is critical for scaling to frontier reasoning tasks.
  Apply ▸ [weekend-build] Implement off-context rollouts for a math/code task where standard GRPO fails, measure reward distribution shift. — via **arxiv:2607.19313 + GRPO**
- **[Prompt Design at Scale: How Format, Instruction Count, and Context Length Shape Instruction Adherence and Hallucination in Large Language Models](https://arxiv.org/abs/2607.19257v1)** `[deep,high_value]`
  Controlled experiments on prompt format (markdown vs. prose vs. tabular), instruction count, and context length using a contamination-free synthetic corpus (Book of Veyra). Quantifies compliance and hallucination degradation across all three axes. Prompt-design decisions are made daily with almost no controlled evidence; this fills the gap.
  Apply ▸ [read] Replicate the format and instruction-count experiments on your domain prompts to identify failure modes. — via **arxiv:2607.19257 + Book of Veyra**

## Pattern watch

**HOT+DEEP: RLVR infrastructure & failure modes** – Multiple papers (Off-Context GRPO, ISO optimization, Copy Less Ground More) dissect RLVR training dynamics, zero-signal cliffs, and spectral inheritance; ResearchArena and AgentDebugX provide eval/debug tooling for production agents. **HOT: Eval methodology for completeness & control** – GAMUT (factual completeness), ResearchArena (AI control monitors), and prompt-design experiments (format/instruction/context) all tackle the "what are we actually measuring?" gap. **HIGH-VALUE: DX tooling bridges agent → artifact** – DataFlow-Harness (NL2Pipeline DAGs), CircuitKIT (unified circuit workflows), and AgentDebugX (root-cause attribution) address the "agents produce throwaway code" problem.
